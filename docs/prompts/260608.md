- macOS 전용 네이티브앱
- 메뉴바에서 동작하면서 등록된 곳으로 주기적으로 ping 을 전송하여 정상 상태 인지 여부 확인

## 동작 방식
- 설정 창에서 ping 을 전송할 호스트 주소 입력 (여러개)
- 백그라운드에서 5초 마다(타임아웃 5초) ping 전송해서 응답 시간 측정
- 호스트들은 메뉴바에서 세로형 바로 표현되며 (호스트당 1개) 응답 속도 및 상태에 따라서 다른 색 표현
	- 초록 = 최근 10건 평균 50ms 미만 
	- 파랑 = 최근 10건 평균 100ms 미만
	- 노랑 = 최근 10건 평균 200ms 미만 / 최근 10건 데이터 부족
	- 주황 = 최근 10건 중 Timeout 또는 기타 네트워크 관련 에러 1건 이상 발생
	- 빨강 = 최근 5건 중 4건 이상 오류
- 설정 가능 항목
	- 백그라운드 검사 주기(5초) / 타임아웃 처리 시간(3초)
	- 포어그라운드 검사 주기(1초) / 타임아웃 처리 시간(1초)
- 알림 발생 조건
	- 초록, 파랑 (정상 범주) => 노랑 주황 빨강(에러 범주) 으로 전환
	- 노랑, 주황, 빨강 : 각 단계 변경
	- 정상 범주 내에서 전환은 알림 없음
- 메뉴바 클릭시 Ststs 처럼 등록된 호스트들 응답 속도 차트 표현
	- 1초 마다 갱신, 현재 시간 표시 (HH:mm:ss)
	- 최근 5분(또는 제시) ping 응답 시간 추이
