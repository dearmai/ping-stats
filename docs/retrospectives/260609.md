# PingStats 개발 회고

작성일: 2026-06-09

## 요약

PingStats는 macOS 메뉴바에서 여러 대상의 네트워크 상태를 짧은 주기로 확인하는 네이티브 앱으로 구현했다. 초기 요구사항은 IP 기반 ping 모니터링이었지만, 이후 이름 지정과 `IP:port` 기반 TCP 연결 측정까지 확장했다. 현재 앱은 Swift Package Manager 기반으로 빌드되며, AppKit으로 메뉴바 상태 아이템을 만들고 SwiftUI로 팝오버와 설정 창을 구성한다.

## 잘된 점

- 외부 의존성 없이 SwiftPM, AppKit, SwiftUI, Network 프레임워크만으로 구현해 빌드 구조가 단순하다.
- 메뉴바에는 호스트별 세로 컬러 바를 표시하고, 팝오버에서는 2열 차트로 최근 5분 응답 추이를 볼 수 있게 했다.
- 기존 단순 호스트 문자열 설정을 `name + address` 대상 모델로 확장하면서 기존 저장값을 자동 마이그레이션하도록 했다.
- `IP`는 ping, `IP:port`는 TCP connect latency로 동작하도록 분기해 실제 서비스 포트 상태 확인까지 가능해졌다.
- Xcode/SwiftPM 툴체인 문제, GitHub Actions self-hosted runner 문제, macOS 키체인 비대화형 권한 문제를 각각 분리해서 해결했다.

## 아쉬운 점

- macOS 셀프 서명 인증서는 CI에서 자동 신뢰 설정을 할 수 없어서, GitHub Actions 릴리즈 산출물은 ad-hoc 서명을 사용한다.
- 현재 TCP 대상 파싱은 `host:port` 형태에 맞춰져 있어 IPv6 주소 입력은 별도 처리가 필요하다.
- 설정 화면은 기본적인 행 편집 형태로 구현되어 있지만, 대상 수가 많아질 경우 검색, 정렬, 일괄 편집 같은 기능은 아직 없다.
- 알림 정책은 상태 전환 중심으로 구현했지만, 알림 음소거, 대상별 알림 설정, 반복 알림 억제 같은 운영 편의 기능은 남아 있다.

## 기술적 결정

- SwiftPM 실행 파일을 `.app` 번들로 패키징하는 스크립트를 별도로 두었다.
- `/sbin/ping`을 `Process`로 실행해 ICMP 응답 시간을 측정했다.
- TCP 측정은 `NWConnection`의 `.ready` 도달 시간을 기준으로 계산했다.
- 상태 판정은 최근 샘플 기반으로 유지했다.
  - 최근 5건 중 오류 4건 이상이면 빨강.
  - 최근 10건 중 오류가 있으면 주황.
  - 최근 10건이 부족하거나 평균 100 ms 이상이면 노랑.
  - 평균 50 ms 미만이면 초록, 100 ms 미만이면 파랑.
- CI에서는 키체인 trust 변경 없이 ad-hoc 서명으로 zip 패키지를 만든다.

## 다음 개선 후보

- IPv6와 도메인 입력 지원 범위를 명확히 정리하고 파서 확장.
- 대상별 알림 on/off, 임계값 커스터마이징.
- 설정 화면에서 대상 reorder, duplicate 감지, 입력 검증 메시지 추가.
- 차트에 timeout/error 마커와 평균선 표시.
- 정식 배포를 위한 Developer ID 서명 및 notarization workflow 추가.

## 배운 점

macOS 네이티브 앱은 코드 구현뿐 아니라 툴체인, 번들 구조, 서명, 키체인 권한, Gatekeeper 정책까지 함께 고려해야 한다. 특히 self-hosted GitHub Actions는 로컬 머신처럼 보이지만 비대화형 세션이므로 `sudo`, 키체인 trust 변경, GUI 승인 흐름은 CI 단계에서 실패하기 쉽다. 배포 자동화는 가능한 작업과 사용자 승인이 필요한 작업을 명확히 분리하는 쪽이 안정적이다.
